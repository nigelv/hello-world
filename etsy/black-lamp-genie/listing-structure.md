# Etsy listing structure — Black Lamp Genie

Use this skeleton for every food-label tee. Replace bracketed placeholders. Keep section order the same so the shop feels consistent.

---

## 1. Title (max 140 characters)

```
[Funny hook] | [Theme] Food Label Shirt | Funny [Occasion] Tee | Black Lamp Genie
```

**Rules**

- Lead with the joke people would search for.
- Include “food label,” “shirt” or “tee,” and “funny.”
- End with **Black Lamp Genie**.
- No emojis. No ALL CAPS except short acronyms in the design name.

**Example**

```
Hot Sauce Personality Label | Funny Food Label Shirt | Gag Gift Tee | Black Lamp Genie
```

---

## 2. Photos (upload in this order)

| # | Shot | Notes |
|---|---|---|
| 1 | Hero flat lay or mockup | Clean background; full design readable |
| 2 | Model / lifestyle | Real person wearing the tee if possible |
| 3 | Print close-up | Show label detail and ink quality |
| 4 | Alternate color | Second shirt color if offered |
| 5 | Size chart | Clear measurements |
| 6 | Gift / context | Wrapped, kitchen, brunch table, etc. |
| 7 | Brand / logo card (optional) | Early logo or shop mark — small, not covering the joke |

**Alt-text style captions** (for your own file names / accessibility notes): `[Design name] Black Lamp Genie funny food label t-shirt — [shot type]`

---

## 3. Price & variants

| Field | Suggested default |
|---|---|
| Base price | Set to your POD cost + ≥40% margin |
| Variations | **Size** (S–3XL) + **Color** (e.g. Black, White, Soft Cream) |
| Personalization | Off by default; enable later for custom label name |
| Quantity | Unlimited / made to order |
| Processing time | Match your printer (e.g. 2–5 business days) |

---

## 5. Tags (exactly 13)

Mix: **niche** (food label / funny food) + **intent** (shirt / tee / graphic tee) + **gift** (birthday / gag gift) + **1–2 design-specific** words.

See [`tags-and-seo.md`](tags-and-seo.md) for a shared bank and per-listing sets.

---

## 6. Materials & production

```
Materials: 100% cotton (or cotton blend per colorway) soft unisex tee; water-based / DTG or equivalent apparel print
Production: Made to order
```

Adjust fiber % to match your blank (e.g. Bella+Canvas 3001).

---

## 7. Category & attributes

| Field | Value |
|---|---|
| Category | Clothing › Unisex Adult Clothing › Tops & Tees › T-shirts |
| Who made it | I design / someone else makes (or your POD setup) |
| What is it | A finished product |
| When made | Made to order |
| Primary color | Match first variation |
| Occasion | Birthday / Everyday (add seasonal when relevant) |

---

## Quick QA before publish

- [ ] Title ≤ 140 characters and includes Black Lamp Genie  
- [ ] Exactly 13 tags, no trademarked brand names  
- [ ] Description has hook → design → details → care → gifts → shipping → brand closer  
- [ ] Photos 1–5 minimum uploaded  
- [ ] Joke is original parody, not a real label clone
