# Black Lamp Genie — Etsy listing kit

Paste-ready listing copy and structure for **Black Lamp Genie** funny food-label T-shirts.

## Brand

| | |
|---|---|
| **Name** | Black Lamp Genie |
| **Niche** | Funny food-label / parody packaging tees |
| **Angle** | Grocery-aisle humor: fake nutrition facts, “ingredients,” vintage can labels, condiment warnings |
| **Voice** | Dry, cheeky, gift-friendly — never mean-spirited |
| **Audience** | Foodies, home cooks, brunch people, gag-gift buyers (birthdays, Father’s Day, white elephant) |
| **Product** | Unisex soft cotton tee; sizes + colors; print-on-demand friendly copy |

### Early logo

See [`logo-early.jpg`](logo-early.jpg) — black-and-white silhouette of a genie rising from an ornate oil lamp. Use it for shop branding, about section, and listing watermarks once you confirm you have commercial rights to the final artwork. Prefer an original or properly licensed mark before publishing on Etsy.

**Visual direction:** high-contrast B&W, bold silhouette, mystical-but-playful. Pair shirt designs with clean label typography so the brand mark and the joke print don’t compete.

## How to ship a new listing

1. Pick a joke concept that does **not** copy a real brand name, logo, or trade dress.
2. Fill [`listing-structure.md`](listing-structure.md) using the title formula in [`tags-and-seo.md`](tags-and-seo.md).
3. Paste title, description, and exactly **13 tags** into Etsy.
4. Upload photos in the order listed in the structure file.
5. End the description with: *Black Lamp Genie — wishes granted in soft cotton.*

## Legal / trademark note

Original parody concepts only. Do not use real food brand names, logos, mascots, or lookalike packaging in titles, tags, or artwork.
