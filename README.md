# Skyline Weather

A simple, atmospheric weather forecast app.

## Features

- Search any city worldwide
- Current conditions with feels-like, humidity, and wind
- 7-day forecast with condition-aware sky backgrounds
- Optional geolocation on first load

Weather data comes from the free [Open-Meteo](https://open-meteo.com/) API (no API key required).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
